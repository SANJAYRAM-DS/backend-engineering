# 11 — Base62 Encoding from First Principles

## 1. Learning Objective
Understand number bases (Binary Base-2, Decimal Base-10, Hexadecimal Base-16, Base64, Base62) and implement a custom Base62 encoder/decoder from scratch.

---

## 2. Why Base62 for URL Shorteners?
- **Base10 (Digits 0-9)**: A 6-digit number gives only $10^6 = 1,000,000$ combinations.
- **Base16 (Hex 0-9, a-f)**: Gives $16^6 = 16,777,216$ combinations.
- **Base64 (0-9, a-z, A-Z, +, /)**: Contains reserved URL characters (`+`, `/`, `=`) requiring URL encoding.
- **Base62 (0-9, a-z, A-Z)**: Contains 62 URL-safe alphanumeric characters. A 7-character string yields $62^7 = 3.52 \text{ Trillion}$ unique combinations!

---

## 3. Mathematical Encoder Algorithm

To convert integer ID $N$ to Base62 string:
1. Divide $N$ by 62.
2. The remainder gives the character index in alphabet `0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ`.
3. Repeat division with quotient until quotient becomes 0.
4. Reverse character array.

### Python Implementation Code (`src/services/base62.py`)
```python
BASE62_ALPHABET = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"

def encode_base62(num: int) -> str:
    if num == 0:
        return BASE62_ALPHABET[0]
    result = []
    base = 62
    while num > 0:
        num, rem = divmod(num, base)
        result.append(BASE62_ALPHABET[rem])
    return "".join(reversed(result))

def decode_base62(string: str) -> int:
    base = 62
    num = 0
    for char in string:
        num = num * base + BASE62_ALPHABET.index(char)
    return num
```
